## Brand & Style

This design system establishes a high-performance, futuristic developer and enterprise workspace for cross-lingual NLP engineering—specifically specialized in processing code-mixed South Asian linguistic data (Kannada script, Latin Kannada, and English). 

The visual identity marries **deep slate glassmorphism** with **hyper-luminous computational accents**. It evokes the cognitive precision of modern developer tools (such as modern IDEs and model observatories) while delivering the refined polish of high-end AI research products. Interfaces must balance analytical density with expansive visual breathing room.

Key aesthetic pillars:
- **Luminescent Depth:** Deep neutral backgrounds set the stage for controlled translucent layers, subtle specular borders, and optical glows that convey real-time machine intelligence.
- **Multilingual Clarity:** Equal visual prestige is afforded to Kannada script (`ಕನ್ನಡ`) and Latin typography, ensuring matched baselines, optical balance, and effortless legibility.
- **Semantic Differentiation:** Color is deployed structurally to decode linguistic morphology at a glance (Kannada morphemes vs. English syntactic structures vs. hybrid enclitics).

## Colors

The system relies on an inky, high-contrast dark mode foundation that prevents eye fatigue during intensive annotation and dataset inspection, punctuated by high-chroma computational signals.

### Palette Architecture
- **Primary (Electric Violet & Deep Indigo):** `#7C3AED` to `#4F46E5`. Anchors primary interactions, generative states, active node links, and synthetic generation processes.
- **Secondary (Neon Cyan & Electric Blue):** `#06B6D4` to `#3B82F6`. Denotes English language tokens, Latin phonetic transcriptions, system metrics, and precision diagnostic overlays.
- **Tertiary (Luminous Magenta & Neon Coral):** `#F43F5E` to `#D946EF`. Directs user focus to high-priority anomalies, code-switching transition boundaries, and interactive accent states.
- **Neutral Canvas:** Base ground `#090D16`, elevated surface `#0F172A`, floating glass panels `#1E293B` at 70% opacity. Border lines sit at `rgba(255, 255, 255, 0.08)`.

### Semantic Linguistic Categorization Tokens
- **Kannada (Dravidian Lexicon & Script):** Luminous Warm Saffron / Amber Coral (`#F59E0B` to `#FB923C`). Denotes native script segments, Dravidian roots, and morphological stems.
- **English (Latin Lexicon):** Electric Cyan (`#06B6D4`). Denotes borrowed English nouns, grammatical tags, and western syntax anchors.
- **Code-Mixed & Enclitic Hybrids:** Radiant Fuchsia / Violet (`#C026D3` to `#8B5CF6`). Highlights agglutinated tokens (e.g., Kannada suffix attached to an English verb/noun such as "Open-maadi" or "Fast-aagi").

## Typography

The typographic hierarchy establishes clear structural bounds between UI control layers, human-generated conversational text, and machine-level semantic token arrays.

- **Plus Jakarta Sans** serves as the universal UI, heading, and body font. Its geometric structure and open counters provide exceptional legibility across complex bilingual dashboard panels. When rendering Kannada unicode characters, fallback chains cascade smoothly into system Indic font rendering engines without vertical baseline jitter.
- **JetBrains Mono** acts as the analytical workhorse. It is utilized for raw transliteration string matrices, PoS (Part-of-Speech) tagging, confidence metric floats, embeddings tensors, and API JSON inspectors.
- All uppercase labels (`label-caps`) employ wide letter-spacing (`0.06em`) to preserve legibility when set against colored badge surfaces.

## Layout & Spacing

This design system operates on an 8-point baseline grid, scaling to a 4-point micro-scale for compact data tables, token badges, and sidebar inspectors.

### Grid Architecture
- **Desktop (1280px and above):** 12-column fluid grid, `2rem` page margins, `1.5rem` gutters. Accommodates multi-pane layouts: collapsible linguistic taxonomy tree (left), main interactive tokenization engine (center), and token attribution / confidence inspector (right).
- **Tablet (768px - 1279px):** 8-column layout, `1.5rem` margins, `1rem` gutters. The inspector moves into an overlay slide-out drawer or persistent bottom sheet.
- **Mobile (Below 768px):** 4-column layout, `1rem` margins, `0.75rem` gutters. Token matrix displays reflow into continuous horizontal wrap containers with sticky action drawers.

### Spacing Application
- Component internal padding uses strict tokens: `space-xs` and `space-sm` for pill tabs and badges; `space-md` and `space-lg` for card containers and parameter control groups.
- Sections and workbench panels are separated by `space-xl` through `space-3xl`.

## Elevation & Depth

Visual depth relies on a layered glassmorphic schema paired with controlled atmospheric neon luminescence rather than standard opaque dropshadows.

### Layer Hierarchy
1. **Canvas Surface (Level 0):** Deepest void `#090D16` featuring radial micro-gradients of indigo (`rgba(79, 70, 229, 0.08)`) and cyan (`rgba(6, 182, 212, 0.05)`) positioned dynamically behind primary interactive canvases.
2. **Structural Panels (Level 1):** Solid `#0F172A` with a 1px border of `rgba(255, 255, 255, 0.06)`. Used for navigation rails and sidebars.
3. **Glassmorphic Interactive Cards (Level 2):** Translucent `#131D31` at 75% opacity with `backdrop-filter: blur(16px)` and a subtle interior highlight border: `1px solid rgba(255, 255, 255, 0.12)`.
4. **Active & Floating Focus Elements (Level 3):** Modal overlays, dropdown matrices, and hovering code tokens utilize translucent dark surfaces accented with radiant rim lighting:
   - Primary Interactive Glow: `box-shadow: 0 0 0 1px rgba(124, 58, 237, 0.4), 0 8px 32px -4px rgba(124, 58, 237, 0.25)`
   - Cyan Data Glow: `box-shadow: 0 0 0 1px rgba(6, 182, 212, 0.4), 0 8px 24px -4px rgba(6, 182, 212, 0.2)`
   - Kannada Saffron Glow: `box-shadow: 0 0 0 1px rgba(245, 158, 11, 0.4), 0 6px 20px -4px rgba(245, 158, 11, 0.2)`

## Shapes

The geometric framework balances high-tech precision with welcoming, tactile ergonomics:
- **Base Rounding (`0.5rem` / 8px):** Applied to form fields, inline code snippets, parameter steppers, and table row groupings.
- **Card & Modal Rounding (`1rem` / 16px):** Applied to workspace cards, inference visualizers, and conversational split-screens.
- **Pill Rounding (`9999px`):** Reserved for category badges, language detection indicators, quick-filter chips, and dynamic gradient CTA buttons.

## Components

### Buttons
- **Gradient Primary CTA:** Pill-shaped (`rounded-full`) or rounded (`rounded-lg`), styled with an energetic gradient from `#7C3AED` to `#4F46E5`. Features an optical top border `inset 0 1px 0 rgba(255, 255, 255, 0.25)` and a subtle outward purple halo. Active state scales to `0.98`.
- **Secondary Glass Button:** Translucent slate background (`rgba(30, 41, 59, 0.7)`), 1px white border (`rgba(255, 255, 255, 0.12)`), text `#F8FAFC`. On hover, border color shifts to `#06B6D4` with a gentle electric blue inner highlight.
- **Interactive Pill Actions:** Compact height (`32px`), pill radius, containing an icon and label in `JetBrains Mono` or `Plus Jakarta Sans`.

### Language Categorization Badges & NLP Chips
These chips display token-level linguistic categorization. Built using `JetBrains Mono` 11px/13px, with an internal border and luminous ambient glow:
- **Kannada Badge:** Background `rgba(245, 158, 11, 0.12)`, border `rgba(245, 158, 11, 0.35)`, text `#FBBF24`.
- **English Badge:** Background `rgba(6, 182, 212, 0.12)`, border `rgba(6, 182, 212, 0.35)`, text `#38BDF8`.
- **Mixed / Enclitic Badge:** Background `rgba(192, 38, 211, 0.14)`, border `rgba(217, 70, 239, 0.4)`, text `#E879F9`.
- **Token Structure Display:** In sentence visualizers, chips group the native script above and grammatical transliteration beneath with a dividing hairline.

### Cards & Model Viewports
- Constructed using glassmorphic surfaces (`rgba(19, 29, 49, 0.7)` with `16px` backdrop-blur).
- Bounded by 1px subtle gradients (`linear-gradient(135deg, rgba(255,255,255,0.15) 0%, rgba(255,255,255,0.02) 100%)`).
- Include contextual status dots (`6px` luminous discs) at the top-right indicating model processing states (e.g., streaming inference, parsed, flagged).

### Input Fields & Token Editors
- Background `#0B1120`, inset border `1px solid rgba(255, 255, 255, 0.1)`. Text rendered in `Plus Jakarta Sans` or `JetBrains Mono`.
- **Focus State:** 1px border illumination matching primary violet `#7C3AED` accompanied by a localized ambient glow ring: `0 0 0 3px rgba(124, 58, 237, 0.2)`.
- Kannada text input zones automatically calibrate line-height to `1.6` minimum to prevent diacritic glyph clipping.

### Tabs & Segmented Filters
- Encased in a pill-shaped or rounded background track (`rgba(15, 23, 42, 0.8)`).
- Active segment transitions smoothly using an illuminated glass overlay with a delicate bottom border accent or full violet fill with pure white typography.

### Checkboxes & Radios
- Size `18px`, radius `4px` (checkbox) or `50%` (radio).
- Inactive: Slate background `#1E293B`, 1px border `rgba(255, 255, 255, 0.2)`.
- Active: Vibrant gradient `#7C3AED` to `#06B6D4` with a crisp white check or center pip, illuminated by an outward violet micro-glow.
